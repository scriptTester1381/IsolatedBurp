# Contributing to IsoBurp

Thank you for your interest in making IsoBurp better! To keep this project lean and reliable, I do not accept blind pull requests. Instead, I welcome targeted feedback to ensure the sandbox remains highly portable across the Linux ecosystem.

If you find a bug, a broken dependency, or an issue that prevents these scripts from working out-of-the-box on other Debian-based Linux distributions (such as Kali, Ubuntu, or standard Debian), please feel free to make a pull request, just ensure that you have tested everything first and there isn't any mechanics broken during the change. You can also just reach out directly via email at **danielhunt1381@gmail.com**. Please include the name of the distribution you are using and any relevant terminal error logs so I can keep the environment optimized!
